# 2.1 Spring Boot 快速开始

## 环境要求

| 环境 | 版本要求 |
|------|---------|
| JDK | Spring Boot 2 使用 8+；Spring Boot 3 使用 17+ |
| Maven | 3.6+ |
| Spring Boot | 2.x / 3.x |

## Maven 依赖

```xml
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-db-spring-boot-starter</artifactId>
    <version>8.0.0</version>
</dependency>

<!-- 由应用显式提供 Spring JDBC；版本跟随 Spring Boot Parent/BOM -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-jdbc</artifactId>
</dependency>
```

Starter 中的 Spring JDBC 和自动配置依赖使用 `provided` 范围，不会传递给应用。应用必须显式引入 `spring-boot-starter-jdbc`，并按所用数据库自行引入 JDBC 驱动。

## yaml 配置

```yaml
# application.yml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/test?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: 123456

# DLZ-DB 配置（可选）
dlz:
  db:
     logic-delete-field: deleted
     use-db-sql: false
     helper:
       auto-update: false
       package-name: com.dlz.test.db.entity
     log:
        show-result: true
        show-run-sql: true
        show-caller: true
```

## 自动装配

Starter 同时提供 Spring Boot 2 的 `spring.factories` 和 Spring Boot 3 的 `AutoConfiguration.imports`。配置好 `spring.datasource` 后即可直接使用 `DB.*`，无需编写或继承 DLZ-DB 配置类。

完整配置项、自动装配和 Spring 事务说明见 [4.1 Spring Boot 完整集成](../4.框架集成/4.1-SpringBoot完整集成.md)。
