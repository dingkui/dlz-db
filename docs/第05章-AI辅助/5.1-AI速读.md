# 5.1 AI 速读

本章用于向 AI 工具提供 DLZ-DB 8.0 的最小正确上下文。完整版见 [DLZ-DB 8.0 AI 速读](../ai-docs/dlz-db-速读.md)。

## 可直接提供给 AI 的约束

```text
项目使用 DLZ-DB 8.0.0。

1. 静态入口是 DB.pojo / table / jdbc / sql / batch / ds / tx / config。
2. 无需自写 Mapper/DAO，但会使用框架返回的 Wrapper。
3. Pojo/Table Wrapper 入口为 selectWrapper/insertWrapper/updateWrapper/deleteWrapper。
4. 查询列用 select(...)；复合条件用 ands(...) 和 ors(...)。
5. queryBean* 返回 Pojo，queryOne/List/Page 返回 ResultMap 系列。
6. 分页用 .page(1, 20).queryBeanPage()，或 DB.jdbc.page(sql, PageRequest.of(1, 20), ...)。
7. DB.jdbc 占位符是 ?；DB.sql 和条件 sql() 占位符是 #{key}。
8. 直接 CRUD 立即执行；update/delete Wrapper 以 execute() 结束。
9. DB.batch.* 返回 BatchResult，用 isSuccess() 检查。
10. 不依赖 com.dlz.db.internal.*；Spring Boot Starter 不需要自定义继承配置类。
11. 生成的通用库代码兼容 Java 8，不使用 Map.of 或文本块。
```

## 最小示例

```java
List<User> users = DB.pojo.selectWrapper(User.class)
    .select(User::getId, User::getName)
    .eq(User::getStatus, 1)
    .ors(o -> o.like(User::getName, keyword)
               .like(User::getMobile, keyword))
    .queryBeanList();

Page<User> page = DB.pojo.selectWrapper(User.class)
    .orderByDesc(User::getCreateTime)
    .page(1, 20)
    .queryBeanPage();

DB.pojo.updateWrapper(User.class)
    .set(User::getStatus, 2)
    .eq(User::getId, id)
    .execute();
```

## AI 生成后的快速检查

- 有没有生成不存在的 `.columns/.and/.or/setPage`。
- 有没有将 `Page` 误写成 MyBatis-Plus `IPage`。
- 有没有将 `Page.records` 误写成 `rows`。
- 有没有将 `BatchResult` 当成 boolean 或调用不存在的 `hasFailure()`。
- 有没有生成 `SpringDlzDbConfig`、`JdbcQuery` 或 `com.dlz.db.modal.*` 旧包名。
