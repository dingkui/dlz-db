# DLZ-DB 8.0 文档核对与修正说明

**核对日期**：2026-08-28
**核对对象**：8.0.0 源码、POM、自动配置元数据、测试与三个 Web Demo

## 事实基线

- 公共统一入口为 `DB.pojo/table/jdbc/sql/batch/ds/tx/config`。
- Pojo/Table 使用 `selectWrapper/insertWrapper/updateWrapper/deleteWrapper`。
- 查询列方法为 `.select(...)`，复合条件方法为 `.ands(...)` 和 `.ors(...)`。
- 分页类为 `com.dlz.db.model.Page`；直接 JDBC 分页入口使用 `PageRequest.of(...)`。
- Spring Boot 使用 `SpringDlzDbAutoConfiguration` 自动装配，不需要用户继承框架配置类。
- Solon 入口为 `DlzDbSolonPlugin`，需要容器中存在 `DataSource` Bean。
- 批量操作返回 `BatchResult`，并通过 `isSuccess()` 等方法查看结果。

## 本次修正的问题

1. 删除已不存在的 `SpringDlzDbConfig`、`SpringDlzDbProperties`、`JdbcQuery`、`IPage` 等当前用法。
2. 将 `.columns()` 统一修正为 `.select()`，`.and/.or` 修正为 `.ands/.ors`。
3. 将 `.setPage(...).page(...)` 等旧分页示例修正为 8.0 Wrapper 或 `PageRequest` 用法。
4. 修正 `BatchResult.hasFailure()`、`Page.getRows()`、`count()` 返回 `int` 等与源码不符的描述。
5. 重写已混入 DLZ-KIT 内容的 AI 速读页，并修正 AI 代码模板。
6. 将源码指南的目录树更新为 8.0 实际包名与类名。
7. 将 2026-05-17 测试报告明确标注为 7.0.0 历史快照，与当前 8.0 验证命令分离。
8. 更新 JDK 说明：库主体目标 Java 8，Spring Boot 3 Demo 要求 JDK 17，聚合验证使用 JDK 17+。
9. 按 DLZ-KIT 6.7.4 源码修正配套速读文档：`JSONMap` 继承 `LinkedHashMap`，Bean/Map 转换使用 `ConvertUtil.convert(...)`，不再引用已不存在的 `BeanUtil.copyAsSource/copyAsTarget`。
10. 在本地复现 JDK 8 库模块任务以及 JDK 17/21 完整 reactor 任务；三档均为 1281 个测试、0 失败、0 错误，JDK 17/21 的 JaCoCo 门槛通过。

## 边界说明

本次修正只将文档对齐到当前代码，不把尚未实现的设计写成已有功能。`com.dlz.db.internal.*` 仍是实现细节；如果后续要对外稳定 SPI，应先在代码中提供非 internal 的接口或类，再在用户文档中公开。
