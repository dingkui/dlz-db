# 6.2 v6 升级到 v7（历史迁移记录）

> 本页仅记录 v6 到 v7 的架构变化。当前支持版本为 8.0.0，请不要把历史配置类或包名复制到 8.0 项目。

## 历史背景

v7 将原单模块拆分为框架无关 core、Spring Boot Starter 和 Solon Plugin，核心目标是：

- 核心模块剔除 Spring 依赖。
- 以 `ISqlExecutor` 和 `ITxExecutor` 隔离框架适配。
- Spring Boot 和 Solon 共用 `DB.*` CRUD API。
- 删除应用直接依赖的 `DlzDao/IDlzDao`。

## 从 v6 迁移到当前 8.0

### 1. 替换依赖

```xml
<!-- Spring Boot -->
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-db-spring-boot-starter</artifactId>
    <version>8.0.0</version>
</dependency>
```

```xml
<!-- Solon -->
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-db-solon-plugin</artifactId>
    <version>8.0.0</version>
</dependency>
```

非 Spring/Solon 的手动集成使用 `top.dlzio:dlz-db-core:8.0.0`。

### 2. 删除历史手动配置类

Spring Boot 8.0 的入口是 `SpringDlzDbAutoConfiguration`，Starter 会自动绑定 `dlz.db.*` 并使用容器中的 `DataSource`。应用不应再继承或导入下列历史类名：

- `DlzDbConfig`
- `DlzDbProperties`
- `SpringDlzDbConfig`
- `SpringDlzDbProperties`

### 3. 保留业务 CRUD 调用，核对 8.0 命名

```java
DB.pojo.selectWrapper(User.class).eq(User::getId, id).queryBean();
DB.table.selectWrapper("user").eq("id", id).queryOne();
DB.jdbc.selectWrapper("SELECT * FROM user WHERE id = ?", id).queryOne();
DB.sql.selectWrapper("key.user.find").addPara("id", id).queryOne();
DB.batch.insert(users);
DB.ds.use("slave", () -> DB.pojo.selectById(User.class, id));
DB.tx.run(() -> DB.pojo.insert(user));
```

迁移时重点搜索并修正：

- 查询列使用 `.select(...)`。
- 复合条件使用 `.ands(...)` 和 `.ors(...)`。
- 分页使用 `.page(...).queryBeanPage()` 或 `DB.jdbc.page(..., PageRequest.of(...), ...)`。
- 批处理返回 `BatchResult`。

### 4. 替换 DAO 与 RowMapper 扩展

- 业务层如果直接注入 `DlzDao/IDlzDao`，优先改为 `DB.pojo`、`DB.table`、`DB.jdbc` 或 `DB.sql`。
- 如果确实在开发框架适配，使用 `com.dlz.db.core.ISqlExecutor`。
- 结果行映射 SPI 当前为 `com.dlz.db.dialect.rowMapper.IRowMapper`，不是历史文档中的 `com.dlz.db.core.RowMapper`。

### 5. 事务注解

- Spring Boot：`@Transactional`。
- Solon：`@Tran`。
- 框架无关代码：`DB.tx.run(...)`。
