# 1.5 快速构建 Spring Boot 应用

> 用 dlz-db 从零搭一个可直接运行的 Spring Boot 应用。
> 核心：一个 Controller 直接用 `DB.xx`，**不需要 Mapper / DAO**。Service 层可选（按业务需要）。
>
> **开发原则：首选 `DB.pojo`（实体操作），`DB.jdbc`（原生 SQL）尽量少用或不用。**
> 绝大多数 CRUD 用 `DB.pojo` 链式即可；只有极复杂 SQL（多表 JOIN、窗口函数、动态列）才考虑 `DB.jdbc` 兜底。

## 一、目录结构

```
src/main/
├── java/com/example/demo/

│   └── controller/

└── resources/
    └── application.yml             # spring.datasource + dlz.db 配置
```

## 二、Maven 依赖

> **版本兼容**：dlz-db-spring-boot-starter `8.0.0` 支持 Spring Boot `2.x` `3.x`,spring boot 按需要引入 。

```xml
<!-- Spring Boot Web（构建 Web 应用必须） -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>

<!-- DLZ-DB Spring Boot Starter -->
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-db-spring-boot-starter</artifactId>
    <version>8.0.0</version>
</dependency>

<!-- spring.boot.version: 2.x 3.x -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-autoconfigure</artifactId>
    <version>${spring.boot.version}</version>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-jdbc</artifactId>
    <version>${spring.boot.version}</version>
</dependency>
<!-- 数据库驱动（按需引入：sqlite / mysql / pg） -->
<dependency>
    <groupId>org.xerial</groupId>
    <artifactId>sqlite-jdbc</artifactId>
    <version>3.45.1.0</version>
</dependency>

<!-- Lombok（简化实体类代码，可选但推荐） -->
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
</dependency>
```

> **注意**：
> - 如果是纯后台服务（不需要 Web），可以不加 `spring-boot-starter-web`。
> - Lombok 是可选的，不加的话实体类需要手动写 getter/setter。
> - MySQL / PostgreSQL 驱动需另外引入，见下方"切换数据库"部分。

## 三、配置 application.yml

数据源就是 Spring 的 `spring.datasource` 配置。**切换数据库只改这里**。
默认使用 Spring Boot 自带的 HikariCP 连接池，可通过 `spring.datasource.hikari.*` 调整连接池参数。

```yaml
# SQLite（默认，零配置即可运行）
spring:
  datasource:
    driver-class-name: org.sqlite.JDBC
    url: jdbc:sqlite:./data/demo.sqlite3
    # 连接池配置（可选，HikariCP 参数）
    hikari:
      maximum-pool-size: 10       # 最大连接数
      minimum-idle: 2             # 最小空闲连接
      connection-timeout: 30000   # 连接超时（毫秒）

# MySQL（切库只改这段）
# spring:
#   datasource:
#     driver-class-name: com.mysql.cj.jdbc.Driver
#     url: jdbc:mysql://localhost:3306/demo?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8
#     username: root
#     password: 123456

# PostgreSQL（切库只改这段）
# spring:
#   datasource:
#     driver-class-name: org.postgresql.Driver
#     url: jdbc:postgresql://localhost:5432/demo
#     username: postgres
#     password: postgres

dlz:
  db:
    # 逻辑删除字段（Bean 含该字段时自动启用）
    logic-delete-field: deleted
    helper:
      # 扫描哪些包下的实体，自动建表/同步字段
      package-name: com.example.demo.entity
      # 是否自动建表/加字段。开发环境 true；生产建议 false（避免误改表结构）
      auto-update: true
    log:
      show-run-sql: true    # 打印执行的 SQL
      show-caller: true     # 打印 SQL 调用位置（类名+方法名+行号），方便定位
      show-result: false    # 打印查询结果（调试时开启，数据量大时建议关闭，避免日志爆炸）
    # 是否从数据库加载预设 SQL（配合 DB.sql 使用，详见"预设SQL"章节）
    use-db-sql: false
    # 预设 SQL 的扫描路径（classpath 下的 sql 目录）
    sqllist:
      - app/*
      - demo/*
```

## 五、实体类

```java
package com.example.demo.entity;

import com.dlz.db.core.anno.TableField;
import com.dlz.db.core.anno.TableId;
import com.dlz.db.core.anno.TableName;
import lombok.Data;

import java.util.Date;

@Data
@TableName("user")            // 指定表名（不写则驼峰转下划线 user）
public class User {
    @TableId                    // 主键
    private Long id;
    private String name;
    @TableField(comment = "年龄")
    private Integer age;
    private String email;
    private Integer deleted;    // 逻辑删除字段（含 deleted 自动启用）
    private Date createTime;
}
```

实体字段类型自动映射为数据库列类型（`Long`→BIGINT、`String`→VARCHAR、`Integer`→INT、`Date`→DATETIME 等），`@TableField(comment = "...")` 会生成列中文注释（DDL `COMMENT`）。

### 主键生成策略

`@TableId` 标记主键字段，默认行为：

| 数据库        | 默认策略               | 说明                                  |
|------------|--------------------|-------------------------------------|
| MySQL      | 自增（AUTO_INCREMENT） | 建表时主键列自动加 `AUTO_INCREMENT`，插入后回填主键  |
| SQLite     | 自增（AUTOINCREMENT）  | SQLite 的 `INTEGER PRIMARY KEY` 自带自增 |
| PostgreSQL | 序列（SERIAL）         | 建表时主键列使用 `SERIAL` 类型                |

> **注意**：`DB.pojo.insert(entity)` 执行后会自动将生成的主键回填到 entity 对象中。

### 逻辑删除字段

实体类中包含名为 `deleted`（或通过 `logic-delete-field` 自定义的字段名）的字段时，DLZ-DB 自动启用逻辑删除：

- **查询**：自动加 `WHERE deleted = 0` 条件
- **删除**：自动改为 `UPDATE SET deleted = 1`，不是真的 DELETE
- **绕过逻辑删除**：加 `.ignoreLogicDelete(true)` 可执行物理删除

> **重要**：插入数据时记得手动设置 `deleted = 0`，框架不会自动填充默认值。

### 时间字段

`createTime`、`updateTime` 等时间字段**不会自动填充**，需要在业务代码中手动 set：

```java
user.setCreateTime(new Date());
DB.pojo.insert(user);
```

## 六、自动建表 & 同步数据库（重点）

**只需定义实体 + 配置扫描路径，启动时自动建表；表已存在但缺字段时自动加列。**

原理：
1. 启动时 `DlzDbAdapter` 读取 `dlz.db.helper` 配置。
2. `HelperScan.scan(package-name)` 扫描该包下所有带 `@TableName` 的类。
3. 表不存在 → `createTable`（按实体字段建表）。
4. 表存在但缺某字段 → `createColumn`（自动加列）。

```yaml
dlz:
  db:
    helper:
      package-name: com.example.demo.entity   # 扫这里
      auto-update: true                       # 开自动建表/加列
```

> 实体 `User` 定义在 `com.example.demo.entity` 下，配好上面后**无需手动执行建表 SQL**，启动即自动创建 `user` 表；后续给实体加字段，重启自动 `ALTER TABLE` 加列。
> **注意**：`auto-update: true` 只适合开发/测试；生产建议关闭，避免误改线上表结构。

## 七、Service 层（可选）

简单的 CRUD 可以直接在 Controller 里写 `DB.xx`，不需要 Service 层。复杂业务按需加 Service：

```java
package com.example.demo.service.impl;

import com.dlz.db.DB;
import com.example.demo.entity.User;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class UserService {

    public User getById(Long id) {
        return DB.pojo.selectWrapper(User.class).eq(User::getId, id).queryBean();
    }

    public List<User> listByName(String name) {
        return DB.pojo.selectWrapper(User.class)
                .like(name != null && !name.isEmpty(), User::getName, name)
                .queryBeanList();
    }

    public User create(User user) {
        DB.pojo.insert(user);   // 自动回填主键
        return user;
    }

    public int update(User user) {
        return DB.pojo.updateWrapper(user).eq(User::getId, user.getId()).execute();
    }

    public int delete(Long id) {
        return DB.pojo.deleteWrapper(User.class).eq(User::getId, id).execute();
    }
}
```

> Service 里同样直接 `DB.xx`，**不写 Mapper / DAO**。事务方法加 `@Transactional` 即可。

## 八、Controller —— 业务简单无复用事务需求情况直接用 DB.xx，不需要 DAO

```java
package com.example.demo.controller;

import com.dlz.db.DB;
import com.dlz.db.modal.dto.Page;
import com.example.demo.entity.User;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/user")
public class UserController {

    // 单条查询
    @GetMapping("/{id}")
    public User get(@PathVariable Long id) {
        return DB.pojo.selectWrapper(User.class).eq(User::getId, id).queryBean();
    }

    // 列表查询（条件可选）
    @GetMapping
    public List<User> list(@RequestParam(required = false) String name) {
        return DB.pojo.selectWrapper(User.class)
                .like(name != null && !name.isEmpty(), User::getName, name)
                .orderByDesc(User::getCreateTime)
                .queryBeanList();
    }

    // 分页
    @GetMapping("/page")
    public Page<User> page(@RequestParam(defaultValue = "1") int pageNum,
                           @RequestParam(defaultValue = "10") int pageSize) {
        return DB.pojo.selectWrapper(User.class)
                .page(Page.build(pageNum, pageSize))
                .queryBeanPage();
    }

    // 新增（自动回填主键）
    @PostMapping
    public User create(@RequestBody User user) {
        DB.pojo.insert(user);
        return user;
    }

    // 更新
    @PutMapping("/{id}")
    public int update(@PathVariable Long id, @RequestBody User user) {
        return DB.pojo.updateWrapper(user).eq(User::getId, id).execute();
    }

    // 删除
    @DeleteMapping("/{id}")
    public int delete(@PathVariable Long id) {
        return DB.pojo.deleteWrapper(User.class).eq(User::getId, id).execute();
    }
}
```

### 分页返回结构

`Page<T>` 包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `total` | `long` | 总记录数 |
| `records` | `List<T>` | 当前页数据列表 |
| `pageNum` | `int` | 当前页码（从 1 开始） |
| `pageSize` | `int` | 每页大小 |

返回 JSON 示例：
```json
{
  "total": 100,
  "records": [{"id": 1, "name": "张三", ...}],
  "pageNum": 1,
  "pageSize": 10
}
```

### 更新时 null 字段的处理

`DB.pojo.updateWrapper(entity)` 默认会将实体中**所有非 null 字段**拼入 UPDATE 的 SET 子句。null 值的字段**不会被更新**（保持数据库原值）。

```java
User user = new User();
user.setId(1L);
user.setName("新名字");
user.setAge(null);  // age 为 null，不会被更新

// 实际执行：UPDATE user SET name = ? WHERE id = ?
// age 字段保持不变
DB.pojo.updateWrapper(user).eq(User::getId, 1L).execute();
```

> 如果需要强制把某个字段更新为 null，需使用原生 SQL（`DB.jdbc.execute(...)`）。

## 九、原生 SQL（DB.jdbc）—— 兜底用，少用

**`DB.pojo` 能解决的都优先用 `DB.pojo`。** 只有遇到 `DB.pojo` 难以表达的复杂 SQL（多表 JOIN、窗口函数、动态列、复杂聚合）才用 `DB.jdbc` 兜底：

```java
// 复杂查询返回 ResultMap（Map 结构）
List<ResultMap> rows = DB.jdbc.selectWrapper(
        "SELECT u.name, COUNT(o.id) AS cnt FROM user u " +
        "LEFT JOIN orders o ON o.user_id = u.id GROUP BY u.id", 18).queryList();

// 写操作以 .execute() 结尾
DB.jdbc.execute("UPDATE user SET age = ? WHERE id = ?", 26, 1);

// 统计
long count = DB.jdbc.count("SELECT COUNT(*) FROM user WHERE deleted = 0");
```

> 提醒：能用 `DB.pojo` 表达的单表 CRUD、分页、条件查询，**不要用 `DB.jdbc`**（实体操作有类型安全、逻辑删除自动过滤、驼峰映射等优势）。

## 十一、扩展成"完整应用"

启动类 + Controller 就是一个完整可运行的 Spring Boot 应用。在这个基础上：
- 加 **REST API / 认证**（Spring Security / 简单拦截器）
- 加 **UI**（`src/main/resources/static/` 放前端页面）
- 加 **WebSocket**（实时推送）

即可扩展成 console 控制台，数据访问始终 `DB.xx`，**无需 DAO / Service / Mapper**。

## 十二、快速验证

启动成功后，可以用下面的命令快速验证接口是否正常：

```bash
# 1. 新增一个用户
curl -X POST http://localhost:8080/user \
  -H "Content-Type: application/json" \
  -d '{"name":"张三","age":25,"email":"zhangsan@example.com","deleted":0}'

# 2. 查询用户列表
curl http://localhost:8080/user

# 3. 分页查询
curl "http://localhost:8080/user/page?pageNum=1&pageSize=10"

# 4. 根据 ID 查询（把 1 换成上一步返回的真实 ID）
curl http://localhost:8080/user/1

# 5. 更新用户
curl -X PUT http://localhost:8080/user/1 \
  -H "Content-Type: application/json" \
  -d '{"name":"张三丰","age":26}'

# 6. 删除用户（逻辑删除）
curl -X DELETE http://localhost:8080/user/1

# 7. 统计用户总数
curl http://localhost:8080/user/count
```

同时观察控制台日志，`show-run-sql: true` 和 `show-caller: true` 会打印出执行的 SQL 以及调用位置，方便调试。

## 十三、常见问题 FAQ

### Q1：启动时报 `NoClassDefFoundError` 或 `ClassNotFoundException`
检查依赖是否完整：
- 确认 `dlz-db-spring-boot-starter` 版本正确
- 确认数据库驱动已引入（SQLite/MySQL/PostgreSQL 至少一个）
- 用 `mvn dependency:tree` 检查依赖冲突

### Q2：表没有自动创建
排查步骤：
1. 确认 `dlz.db.helper.auto-update: true`
2. 确认 `package-name` 路径正确，是实体类所在的包
3. 确认实体类有 `@TableName` 注解
4. 查看启动日志中是否有建表 SQL 输出
5. 确认数据库连接正常，用户有 CREATE TABLE 权限

### Q3：查询不到数据（表里明明有数据）
大概率是逻辑删除的问题：
- 实体类有 `deleted` 字段时，查询自动加 `WHERE deleted = 0`
- 检查数据的 `deleted` 字段值是否为 0
- 如果是历史数据没有 `deleted` 字段，要么补字段，要么用 `.ignoreLogicDelete(true)` 绕过

### Q4：插入数据后主键没有回填
- 确认主键字段加了 `@TableId` 注解
- 确认数据库支持自增（MySQL 的 AUTO_INCREMENT、SQLite 的 INTEGER PRIMARY KEY、PostgreSQL 的 SERIAL）
- SQLite 注意：主键类型必须是 `INTEGER`（对应 Java `Long`/`Integer`）

### Q5：`DB.pojo.insert(user)` 报错 "table not found"
- 检查 `dlz.db.helper.package-name` 是否扫描到了该实体类
- 检查实体类是否有 `@TableName` 注解
- 确认 `auto-update: true` 是否开启
- 如果是手动建的表，检查表名和实体名是否匹配（驼峰转下划线）

### Q6：更新时想把字段设为 null 怎么办
`updateWrapper` 默认跳过 null 字段。如果需要强制更新为 null，使用原生 SQL：

```java
DB.jdbc.execute("UPDATE user SET email = NULL WHERE id = ?", 1L);
```

### Q7：`@ConfigurationPropertiesScan` 可以不加吗
不可以。这个注解负责把 `application.yml` 中的 `dlz.db.*` 配置绑定到 `SpringDlzDbProperties` 对象上。
不加的话 dlz-db 读不到配置，会使用默认值（比如 `auto-update` 默认为 false，表不会自动创建）。

## 附：硬约束速查

| 约束 | 说明 |
|------|------|
| 入口 | `DB.pojo`(有Bean) / `DB.jdbc`(一次性SQL,`?`) / `DB.sql`(预设,`#{key}`) / `DB.tx` / `DB.batch` / `DB.ds`(切库) |
| 占位符 | `DB.jdbc` 用 `?`；`DB.sql`/`sql()` 用 `#{key}`，不混用 |
| 写操作 | update/delete 必须以 `.execute()` 结尾 |
| 查询列 | 用 `.columns(...)` 不是 `.select(...)` |
| 插入 | `DB.pojo.insert(entity)` 直接执行并回填主键，无需 `.execute()` |
| 批量插入 | `DB.batch.insert(list)` 批量插入实体列表 |
| 逻辑删除 | Bean 含 `deleted` 自动启用，物理删/绕过用 `.ignoreLogicDelete(true)` |
| 表名 | 驼峰转下划线；自定义 `@TableName("t_user")` |
| 字段 | 驼峰转下划线；自定义 `@TableField("email_address")` |
| 主键 | `@TableId`，默认自增策略，插入后自动回填 |
| 分页 | `.page(Page.build(pageNum, pageSize))` + `.queryBeanPage()` 返回 `Page<T>` |
| 更新 null | `updateWrapper` 默认跳过 null 字段；需强制置 null 用 `DB.jdbc.execute()` |
| 条件 | `.eq()/.ne()/.gt()/.ge()/.lt()/.le()/.like()/.in()/.between()/.isNull()/.isNotNull()` |
| 排序 | `.orderByAsc(字段)` / `.orderByDesc(字段)` |
| 事务 | Spring 用 `@Transactional`；编程式用 `DB.tx.run(() -> { ... })` |
| 启动注解 | `@ConfigurationPropertiesScan` 不能省，否则 dlz.db 配置不生效 |
