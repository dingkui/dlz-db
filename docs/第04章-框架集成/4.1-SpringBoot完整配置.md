# 4.1 Spring Boot 完整配置

## Maven 依赖

```xml
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-db-spring-boot-starter</artifactId>
    <version>8.0.0</version>
</dependency>
```

## 完整 yaml 配置

```yaml
# application.yml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/test?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: 123456

dlz:
  db:
    # 逻辑删除字段名
    logic-delete-field: deleted
    # 预设 SQL 文件路径（classpath 下的通配符）
    sqllist: [app/*]
    # 是否使用数据库中的预设 SQL
    use-db-sql: false
    # 表结构缓存时间（秒，-1 为不过期）
    table-cache-time: -1
    # 辅助功能
    helper:
      # 自动更新表结构
      auto-update: false
      # 扫描的包名
      package-name: com.example.entity
    # 日志
    log:
      show-result: false
      show-run-sql: true
      show-caller: true
```

## 自动装配

无需编写 Java 配置类。`SpringDlzDbAutoConfiguration` 会自动完成：

- 将 `dlz.db.*` 绑定到 `com.dlz.db.core.DlzDbProperties`；
- 注册动态 `JdbcTemplate`、SQL 执行器和事务执行器；
- 使用应用中的 `DataSource` 初始化 DLZ-DB。

Spring Boot 2 通过 `META-INF/spring.factories` 加载，Spring Boot 3 通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 加载。

## 架构组件

| 组件 | Spring 实现 | 底层 |
|------|------------|------|
| ISqlExecutor | SpringSqlExecutorAdapter | JdbcTemplate |
| ITxExecutor | SpringTxExecutorAdapter | TransactionSynchronizationManager |
