# 3.6 日志调试

## 开启日志

```yaml
dlz:
  db:
    log:
      show-run-sql: true     # 打印可执行 SQL
      show-caller: true      # 将调用位置写入 MDC；需由日志 pattern 显示
      show-result: false     # 打印查询结果（有性能影响）
```

## 日志输出格式

```
query 12ms sql:SELECT * FROM user WHERE id = 1 AND deleted = 0
```

日志特点：

1. **SQL 展示**：`show-run-sql: true` 时展开 JDBC 占位符；为 `false` 时保留 SQL 模板和参数数组。展开后的内容主要用于调试，不应把它当成安全的 SQL 重写器。
2. **执行耗时**：日志消息包含毫秒耗时。
3. **调用位置**：`show-caller: true` 通过 MDC 注入调用方信息；最终是否显示、能否在 IDE 中点击，取决于应用的日志 pattern 和控制台。

## 慢 SQL

```yaml
dlz:
  db:
    log:
      show-run-sql: true
      slow-sql-threshold: 1000   # 慢 SQL 阈值（毫秒），0 表示不启用
```

超过阈值的 SQL 会走 **WARN** 级别分支。当前实现会先检查该 logger 的 INFO 是否开启，因此若将 `com.dlz.db.util.DbLogUtil` 的级别直接设为 WARN，反而可能不会进入慢 SQL 判定。需要慢 SQL 日志时，请保持该 logger 的 INFO 可用。

**示例输出：**
```
WARN [main] c.d.db.util.DbLogUtil - query 1250ms sql:SELECT * FROM user WHERE status = 1
```

**使用建议：**
- 开发环境：设置为 0（不启用）或较大值（如 5000ms）
- 测试环境：设置为 1000ms，发现潜在性能问题
- 生产环境：设置为 500-1000ms，及时发现慢查询
